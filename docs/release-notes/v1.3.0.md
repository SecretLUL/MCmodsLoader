## Updating from v1.2.0

The update to v1.3.0 still runs through the updater built into v1.2.0. That updater
fails when the folder holding `MCmodsLoader.exe` has a path with umlauts or other
non-ASCII characters, `!` or `%` — for example `C:\Users\Jürgen\Downloads`. The app
then closes and stays on v1.2.0.

If that happens, download `MCmodsLoader.exe` below and replace your copy by hand.
On its first start, v1.3.0 removes the files the failed update left behind
(`MCmodsLoader.new.exe`, `update_restart.bat`), and from now on it updates itself
from any folder.

## What's new

### New mods
- **ModernFix**, **Krypton** and **Iris Shaders** join the pack. ModernFix has no build
  for the newest Minecraft versions yet; there it is simply skipped and installed as
  soon as one appears.
- **Distant Horizons** is a new optional mod under Advanced, next to Xaero's Minimap and
  World Map, and off by default. If you already installed it yourself, MCmodsLoader
  picks it up and keeps it up to date.
- Every mod is installed in its newest stable release; alpha and beta builds are only
  used when a Minecraft version has nothing else. Iris always gets the Sodium build it
  was made for.

### Your mods are safer
- Updating a mod only replaces that mod's own jar. Updating Sodium used to delete
  Sodium Extra, and other mods' jars (such as Xaero's Minimap Fair-Play) could be
  taken for curated ones and removed.
- Jars are swapped in one step that can be undone: if an old file is in use because
  Minecraft is still running, nothing changes and you are told why. A run that was
  interrupted is repaired on the next one.
- Downloads are checked against the checksums Modrinth publishes.

### Updates and results you can trust
- Mod updates are found even when the whole pack is already installed.
- The result dialog lists what did not work and why: mods skipped because a library
  from the pack they need is not available, and failed downloads. Mods that have no
  build for your Minecraft version yet are mentioned as a note, not as an error, and
  do not count against "all mods ready".
- An outdated jar that would stop Minecraft from starting is renamed to
  `.jar.disabled` instead of being left in place.
- A failed Fabric install is reported as one, and a missing launcher profile is
  created.

### Fabric and the launcher
- The Fabric installer can no longer hang, and Java is only started from
  `JAVA_HOME`, your `PATH` or the launcher's own runtimes.
- MCmodsLoader warns you when the Minecraft Launcher is open, because it could undo
  the new Fabric profile.
- The version picker starts on the version you already play with Fabric.

### Self-updater
- Rewritten: it works from any folder, checks the download, and puts the previous
  version back if the new one does not start.

### Everything else
- Your choice of optional mods is remembered, and a mod is only removed after you
  switch it off yourself.
- The window stays responsive while the mods folder is scanned, and errors no longer
  close the app.
- Escape and the arrow keys work in the Advanced menu.
- Browse only accepts a real `.minecraft` folder, one with launcher profiles or a
  `versions` folder.
