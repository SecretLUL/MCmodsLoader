## MCmodsLoader is now MCperfBooster

Same app, new name: besides the mods it now also tunes the Java that runs Minecraft.

- Your settings and your choice of optional mods carry over on the first start.
- The repository moved to [SecretLUL/MCperfBooster](https://github.com/SecretLUL/MCperfBooster).
  Old links, and the update check of v1.3.0, are forwarded there by GitHub.
- Updating from v1.3.0 inside the app keeps your file's name, `MCmodsLoader.exe`. You can
  rename it to `MCperfBooster.exe`; nothing depends on the name.
- Updating from v1.2.0: as with v1.3.0, its updater fails when the folder path contains
  umlauts or other non-ASCII characters, `!` or `%`. Download `MCperfBooster.exe` below
  and replace your copy by hand.

## What's new

### Minecraft runs on Oracle GraalVM
- Each Minecraft version gets the Java it needs, as Oracle GraalVM, whose optimizing
  compiler makes the game's code faster:

  | Minecraft | GraalVM |
  | :--- | :--- |
  | 1.16.5 – 1.20.4 | 17.0.12 |
  | 1.20.5 – 1.21.11 | 21.0.12 |
  | 26.1 and newer | 25 (newest 25.0.x, updated automatically) |

- GraalVM is downloaded once per Java version from Oracle (about 300–350 MB), checked
  against its checksum, and unpacked without the parts not needed to play, so it takes
  about 300 MB instead of 600–770 MB. Before the first download MCperfBooster asks.
- It is free to use under the GraalVM Free Terms and Conditions. 17.0.12 and 21.0.12 are
  the last free builds of those versions, so they are not updated any more.
- On laptops with two graphics cards, Minecraft stays on the card you picked in Windows'
  graphics settings for the launcher's Java: GraalVM gets the same choice. MCperfBooster
  never picks a card on its own.
- Don't want it? Untick **Use GraalVM** under **Advanced**: the next injection brings back
  the launcher's own Java and removes the downloaded GraalVM, along with the graphics card
  choice it carried over.

### Java arguments tuned to your PC
- Minecraft gets memory to match your PC: 2 GB on a 4 GB laptop up to 6 GB on PCs with
  24 GB or more, and more with Distant Horizons switched on.
- Garbage collection is tuned for short pauses, and strong processors get deeper
  compiler optimizations. The game's graphics settings are never touched.
- Before GraalVM's arguments are saved, GraalVM is started once with exactly these
  arguments; if that fails, a minimal safe set is tried, and if GraalVM does not start at
  all, Minecraft stays on the launcher's own Java.
- The launcher's own Java only gets arguments its Java version knows: Minecraft 1.16.5
  runs on Java 8 there and 1.17 on Java 16, so those get just the memory settings.
- Only the Fabric profiles of the selected version that use your `.minecraft` folder are
  changed; profiles with their own game directory are left alone.
